## Why

Размер группы сейчас редактируется прямо в шапке и сбрасывается между сессиями браузера. Нужен единый блок пользовательских настроек с сохранением в `localStorage`, чтобы выбранные параметры (в первую очередь размер группы) переживали перезагрузку.

## What Changes

- Добавить клиентские **настройки**, которые сохраняются в `localStorage` и восстанавливаются при старте приложения.
- Перенести выбор **размера группы** из шапки в раздел настроек.
- Редактировать настройки через **левый Drawer** (боковая панель), открываемый из шапки.
- Шапка продолжает показывать ключевые метрики энкаунтера (например сложность и силу группы), но без inline-контрола размера группы.

## Capabilities

### New Capabilities

_(none)_

### Modified Capabilities

- `github-pages-monster-ui`: обновить требования к расположению управления размером группы и добавить поведение панели настроек (левый drawer).
- `client-state`: добавить сохранение пользовательских настроек в `localStorage` (минимум `partySize`) и загрузку при инициализации.

## Impact

- UI шапки (`App.tsx` и/или компонент шапки), новый компонент drawer настроек, Zustand-store (или отдельный settings-store) с `localStorage`-persist.
