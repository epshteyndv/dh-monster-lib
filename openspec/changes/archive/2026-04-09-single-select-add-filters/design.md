## Context

Сейчас фильтры в `AddMonsterModal` реализованы через `MultiSelect` и хранят `string[]` для `tier`/`role`. Пользовательский сценарий поиска обычно подразумевает один конкретный tier и одну конкретную роль.

## Goals / Non-Goals

**Goals:**

- Перевести фильтры `tier` и `role` на single-select контролы.
- Изменить состояние фильтров на одиночные значения (`string | null`), сохранив поведение:
  - `null` = нет ограничения по оси,
  - выбранное значение = фильтр по равенству.
- Сохранить текущий empty-state «Нет монстров по выбранным фильтрам…».

**Non-Goals:**

- Добавление полнотекстового поиска.
- Изменение порядка/набора опций tier/role.

## Decisions

1. Использовать Mantine `Select` (или equivalent single-value control) вместо `MultiSelect`.
2. Для «любой tier/role» использовать `clearable` + `null` state.
3. Фильтрация остаётся AND между `tier` и `role`.

## Risks / Trade-offs

- **[Risk]** Потеря редкого сценария множественного отбора → **Mitigation:** это целевое упрощение UX по запросу, можно вернуть отдельным change.

## Migration Plan

Чисто клиентское изменение без миграции данных.
