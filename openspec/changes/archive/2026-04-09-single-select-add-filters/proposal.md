## Why

Множественный выбор по `tier` и `role` в модалке добавления монстров оказался неудобным для быстрого поиска. Для этой задачи чаще нужен простой фильтр «одно значение tier + одно значение role».

## What Changes

- В оверлее добавления монстров заменить фильтры `tier` и `role` с множественного выбора на **одиночный выбор** (single-select).
- Сохранить текущую логику фильтрации по двум осям (`tier` AND `role`), но каждая ось теперь допускает максимум одно выбранное значение.
- Пустой выбор по оси продолжает означать «любой».

### Modified Capabilities

- `github-pages-monster-ui`: требования к фильтрам в add overlay обновляются с multi-select на single-select для `tier` и `role`.
