## Why

Постоянные метрики в шапке и отдельные настройки перегружают интерфейс. Быстрый обзор по нескольким типовым размерам группы удобнее показывать по наведению на заголовок, без постоянных контролов и без хранения настройки размера группы.

## What Changes

- Убрать из шапки постоянное отображение **сложности** и **силы группы**.
- Убрать из шапки/приложения редактирование размера группы и drawer настроек, связанный с этим сценарием.
- При наведении на заголовок **«Энкаунтер»** показывать подсказку с расчётами для фиксированных размеров группы: **3, 4, 5** игроков.
- Для каждого из значений (3/4/5) показывать пару метрик: `Сложность` и `Сила группы`.

## Capabilities

### New Capabilities

_(none)_

### Modified Capabilities

- `github-pages-monster-ui`: обновить поведение шапки — вместо постоянных метрик/контролов использовать hover-подсказку по заголовку с матрицей 3/4/5.
- `client-state`: убрать обязательность хранения `partySize` как пользовательской настройки для этого сценария.

## Impact

- `App.tsx` (или компонент шапки), удаление/упрощение settings drawer, возможное удаление persisted store для `partySize`, повторное использование существующих функций расчёта сложности/силы для 3/4/5.
