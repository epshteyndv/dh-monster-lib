## Context

Сейчас `partySize` хранится в persisted settings-store, а шапка постоянно показывает `Сложность` и `Сила группы`, плюс есть кнопка/drawer настроек для изменения размера группы. Новый подход: без выбора размера, только быстрый hover-обзор для 3/4/5.

## Goals / Non-Goals

**Goals:**

- По наведению на заголовок `Энкаунтер` отображать popover/tooltip с тремя строками (или компактной таблицей): для группы **3**, **4**, **5**.
- Для каждой строки показывать:
  - `Сложность` (используя текущую формулу `computeEncounterDifficulty(roles, partySize)`),
  - `Сила группы` (`computePartyStrength(partySize)`).
- Убрать постоянные метрики и UI выбора размера группы из header.
- Убрать необходимость settings drawer и persisted `partySize` в контексте этой функции.

**Non-Goals:**

- Изменение формул сложности/силы.
- Добавление произвольного диапазона размеров групп.
- Сохранение выбора размера группы в `localStorage`.

## Decisions

1. Использовать Mantine hover-компонент (`Tooltip` или `Popover`) на заголовке `Энкаунтер`; предпочтительно `Popover` для многорядного контента.
2. Фиксированный набор размеров: `const PARTY_SIZES = [3, 4, 5] as const`.
3. Расчёты делать на лету из текущего энкаунтера (role-массив), без хранения party size в store.
4. Если settings-store больше нигде не нужен, удалить его и связанные элементы UI/спеки.

## Risks / Trade-offs

- **[Risk]** Hover недоступен на тач-устройствах → **Mitigation:** выбрать компонент, который поддерживает tap/focus fallback (Popover with click/focus trigger), либо добавить короткий helper-text.
- **[Risk]** Слишком плотный контент в подсказке → **Mitigation:** компактная типографика/табличный layout.

## Migration Plan

Клиентское изменение без миграции данных; устаревший ключ `localStorage` можно игнорировать или почистить в отдельной задаче.
