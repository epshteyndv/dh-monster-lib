## Why

Сейчас «поделиться» энкаунтером фактически означает копировать текущий URL с `enc`, пока пользователь уже на странице. Отдельная share-ссылка дает явный сценарий: открыть короткий входной URL, один раз подтвердить состав энкаунтера и оказаться на обычной странице с тем же состоянием в `enc`, без смешения с повседневным редактированием.

## What Changes

- Ввести **отдельный** query-параметр для share (например `share`), с тем же форматом payload, что и у `enc` (версионируемый JSON + LZString через `lz-string`).
- При **первой загрузке** с валидным `share`: после готовности каталога **восстановить энкаунтер** из payload и выполнить **`history.replaceState`** на «основной» вид URL: **`share` удалить**, **`enc` выставить** в то же закодированное состояние (как при обычной работе).
- Добавить **отдельную кнопку** в UI (например в шапке рядом с добавлением монстров), которая дает пользователю **share-ссылку** (с `share=`), а не заменяет основной поток работы с `enc` в адресной строке во время редактирования.
