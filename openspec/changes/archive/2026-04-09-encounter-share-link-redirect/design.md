## Context

Приложение статическое (Vite + GitHub Pages), базовый путь задаётся через `base` в Vite. Состояние энкаунтера в URL уже синхронизируется через параметр `enc` и `history.replaceState`. Нужен отдельный вход по share-ссылке с последующим переходом на обычный URL с `enc`.

## Goals / Non-Goals

**Goals:**

- Один канонический параметр **`share`** (имя фиксируем в коде/спеке), значение — **тот же wire-format**, что и у `enc` (см. **Encounter state in URL**).
- При загрузке с `share`: после загрузки каталога — `setEncounterFromIds` по декодированным id, затем **replaceState**: удалить `share`, установить `enc` на эквивалентный закодированный payload (или на пустой `enc`, если энкаунтер пуст после фильтрации неизвестных id).
- Кнопка «Поделиться» / аналог: собирает абсолютный URL текущего origin + **правильный pathname с учётом base** + `?share=<encoded>` (или добавляет/заменяет только query), удобно копировать (clipboard).
- Не создавать лишних записей в history при редиректе share → `enc`: использовать **replace**, не push.

**Non-Goals:**

- Короткие vanity URL или внешний shortener.
- Отдельный HTML-файл или серверный редирект (только клиентский replaceState).
- Изменение формата JSON payload или версии кодека без явного бампа версии.

## Decisions

1. **Имя параметра:** `share` — отделено от `enc`, чтобы не путать «рабочий» URL и «пригласительный».
2. **Порядок обработки:** обработка `share` должна выполняться **до или вместе с** первичной гидратацией из `enc`, так чтобы при наличии **обоих** параметров приоритет за **`share`** (однократное применение, затем канонизация URL с `enc` только). Альтернатива «игнорировать `enc` если есть `share`» — зафиксировать в реализации и тестах.
3. **Сборка ссылки:** использовать `window.location.origin` + путь с учётом `import.meta.env.BASE_URL` (Vite) или эквивалент, чтобы ссылки работали под `/repo/`.

## Risks / Trade-offs

- **[Risk]** Двойная гидратация (сначала `enc`, потом `share`) даёт мигание состояния → **Mitigation:** единый эффект загрузки: если есть `share`, обработать его и **не** применять `enc` из URL в той же сессии загрузки.
- **[Risk]** Слишком длинный payload → **Mitigation:** те же лимиты, что у `enc` (reuse `MAX_ENCOUNTER_URL_PARAM_LENGTH`); кнопка может показать предупреждение или не копировать.

## Migration Plan

Не требуется: старые ссылки с только `enc` продолжают работать.
