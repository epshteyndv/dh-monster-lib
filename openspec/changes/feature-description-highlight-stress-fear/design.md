## Context

Карточка монстра рендерится в React (Mantine). Тело описания фичи сейчас — один `Text` с `whiteSpace: "pre-wrap"` и строкой `f.description` из каталога. Нужно локально обогатить разметку только для слов **Stress** и **Fear**, не меняя источник данных.

## Goals / Non-Goals

**Goals:**

- Целые слова **Stress** и **Fear** в `features[].description` визуально: **жирный + курсив** (Mantine: `fw={700}` + `fs="italic"` или эквивалент на обёртке).
- Сохранить отображение переносов строк в описании (`pre-wrap` на контейнере описания).
- Подсветка только для **целых слов** (не подстрок внутри других токенов).

**Non-Goals:**

- Подсветка в `flavor`, `motives`, названиях фич, статах и т.д.
- Локализация / другие языки / синонимы.
- Изменение схемы YAML/JSON или сборки каталога.

## Decisions

1. **Разбиение строки на сегменты в UI**  
   Разобрать `description` регулярным выражением с границами слова (`\b`) для литералов `Stress` и `Fear`, отрендерить чередование обычных `Text span` и выделенных `Text span` с `fw={700}` и `fs="italic"`.  
   _Альтернатива_: `dangerouslySetInnerHTML` — отклонено (XSS и ненужная сложность для двух слов).

2. **Регистр**  
   Совпадения только для точных форм **`Stress`** и **`Fear`** (как в каталоге английского текста правил). Не подсвечивать произвольный регистр, если в данных позже появятся варианты — это отдельное изменение.

3. **Где живёт логика**  
   Небольшая чистая функция `splitFeatureDescriptionForHighlights(text: string): …` в том же файле или в `src/` утилите рядом с UI — по вкусу команды; предпочтение: один файл, пока логика тривиальна.

## Risks / Trade-offs

- **[Risk]** Редкое слово содержит подстроку `Fear` — **Mitigation**: только `\bFear\b` / `\bStress\b`.
- **[Trade-off]** Если в данных появится `stress` в нижнем регистре, подсветки не будет до смены правил.
